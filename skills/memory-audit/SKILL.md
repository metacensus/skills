**Memory is a proposal nobody else can read.** It holds what one person taught one agent in one place; colleagues, their agents, and this person's agents elsewhere work without it, so a principle kept only there governs some of the work and not the rest. An audit is the decision memory never had.

## The audience names the destination

Of each fact — one memory often holds several — ask who it would serve, and choose the broadest audience whose vast majority would be better for loading it. A fact most of them would skip costs all of them context to help a few. The destination is wherever that audience reads — another repository, the person's own settings — not where the memory was found, and the claim is checked there.

| Audience | Destination |
|---|---|
| this person, this project | the project's memory |
| this person, all their work | the person's user-level memory or instructions |
| everyone in one repository | that repository, at the place the fact governs |
| everyone in the organization | its shared skills or rules, its own choices in a mapping beside them |
| anyone | a general skill |

Within the destination, a rule for one act goes in that act's skill or contract, in the strongest form [`elegance`'s moves](../elegance/SKILL.md#moves) allow.

## Verdicts

- **Retire** — the destination already says it, the work it describes has landed, or it names things that no longer exist. Check the destination for the claim, not the title: grep the facts, open the paths.
- **Migrate** — it serves an audience beyond this person.
- **Keep** — it is about how this person works.
- **Split** — its facts take different verdicts; give each its own.

Open work never stays in memory; the tracker is where someone else can pick it up.

## Landing

The audit proposes and the person decides: memory is theirs, and a deleted memory is not in version control. Give one verdict per memory, naming the destination, and the evidence behind each retire. Each migration lands through its destination's own path, following [`checkin`](../checkin/SKILL.md), or as a proposal to its owner where you cannot write. Retire a migrated memory once its destination has merged, since until then it is the only copy.
