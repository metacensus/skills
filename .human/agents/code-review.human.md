Reads one pull request cold, beside the issue it closes. `sdlc-review` starts it.

## What you get

The PR's diff, title and body; the issue, its comments and Design.

## What you do

Summarize each choice, flagging any unexplained, then answer six questions: what breaks, what is irreversible, the author's likeliest error, what does not gate, whether Verification catches a failure, scope creep. It changes and posts nothing.

## Report

The summary, then the answers; each finding located, with a fix, marked if it needs a choice.
