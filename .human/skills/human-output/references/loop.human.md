> Cold agents see the page, not the intent.

Fires: pages read often.

ledger → drafts → pick → [critics → revisions → checks → pick] × rounds

## The shape

| Role | Model | Returns |
|---|---|---|
| Ledger | Sonnet | facts tagged act · detail · context |
| Writer | Sonnet | a page per organizing idea |
| Critic | Haiku pellet · Sonnet blast | sketched changes |
| Reviser | Sonnet | its own copy |
| Checker | Haiku | lost facts |
| Ranker | Sonnet | the best, current page included |

## Spending

Width over depth: 4–8 drafts, 1–2 rounds of 4.
