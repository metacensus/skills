Sweeps repositories, or one Epic's family, for drift from `sdlc`.

## Precheck

Read the repositories, boards, cadence and required fields, asking the user for the mapping when none is found. Escalate without the `project` scope; stop with no repository.

## Sweep

A `sdlc-sweep` agent per repository flags drift by class; escalate on a short read.

## Read

An `sdlc-family` agent per open Epic asks what the family leaves open.

## Adopt

Each orphan gets an existing parent, a parent to file, or none, checked against the Initiative's non-goals and the board it would join, and goes to the delegator as one outline before anything attaches.

## Act

Run `sdlc-setup.sh`, and `sdlc-status --apply` on each board to settle its columns; escalate the rest, root issues among them, to the sweep's delegator. Close nothing.

## Report

A `Read: escalate` comment of questions per Epic, a count by class; escalate while any wait.
