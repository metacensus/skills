> Coordination is the price of limits: cut work at contract edges, run it in waves, keep the orchestrator's memory for the map.

Fires: asked to parallelize, fan out, or orchestrate; a task spans more units than one agent should carry.

```
Five answers → Classify edges → Cut → Decide → Pin → Waves → Briefs → Integrate → Land
```

## What the work answers

Units · Edges · Action · Done · Checks ([`elegance`'s loop](../elegance/SKILL.human.md#the-review-loop)). Derive a missing one and say so.

## Edges decide the cut

| Edge | Test | Cut? |
|---|---|---|
| Tight | one needs the other's insides | → one unit |
| Contract | small, statable surface | ✅ clean |
| Loose | awareness only | ✅ note what crosses |

## Partition

Cut at contract edges, never finer. Extract the hub first, peel branches, group by owner as a last resort.

## Owning and sharing

One owner per item; write-sets never overlap. Contracts and skills are shared. A change elsewhere is proposed to that owner.

## Decide before fanning out

An unclassifiable edge → ⛔ research first, one agent; the user's decisions go to the user.

## Contracts

Pin them in files. A change makes everything downstream ⚠️ suspect.

## Waves

Run every unit with no unfinished dependency; cap agents by review capacity.

## The brief

Remit · items · write-set · read-set · skills · contracts · neighbours · done · return. A delegated runner runs checks inline; git stays the orchestrator's.

## The model

The caller passes it, by what the agent does:

|Agent|Model|
|---|---|
|flags spans from a list|haiku|
|builds to a confirmed Design · reads work against what is written|sonnet|
|makes a Design · the check a merge or publish waits on|opus|

Named agents carry theirs in `model:`. A handoff's Environment or the person overrides.

## Integrate and land

Run the whole-system check. Report as [`sdlc`'s Reporting](../sdlc/SKILL.human.md#reporting) says; given the branch, commit each unit per [`sdlc-author`'s Open](../sdlc-author/SKILL.human.md#open).
