> Read the state, not the ticket: nothing is written, branched, or launched until the user says go.

Fires: "start ticket"; an issue handed over to plan.

```
Resolve → Gather → What is left → Chunk → Report ⏸️ → go → Run → Self-review
```

## Gather

Issue, comments, referenced PRs and runs · `main`, branches, releases · external state, checked · [`sdlc-author`'s Precheck](../sdlc-author/SKILL.human.md) where mapped, read only.

## Chunk

[`parallelize`](../parallelize/SKILL.human.md) units, each with an owner:

|Owner|Mark|Needs|
|---|---|---|
|agent|🔶|nothing; runs alone|
|person|🩷|a console, credential, admin setting|
|decision|⛔|the user's call, with a recommendation|

De-risk before anything irreversible. ⚠️ a publishing step stops its agent.

## On go

Background agents · report each as it finishes · then [`sdlc-author`'s Self-review](../sdlc-author/SKILL.human.md) where mapped; elsewhere Verification, and the user publishes.
