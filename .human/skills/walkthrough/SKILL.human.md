A walkthrough teaches; nothing changes unless the person asks.

## Pace

One logical block at a time; stop after each for continue, deeper, skip, or a question.

## Order

Types, helpers, I/O, orchestration, tests, deploy wiring; a PR's diff the same way.

## Each chunk

Path and lines; what it does, what breaks without it or that it should go, the simpler shape; where it sits, and whether it is standard or this project's choice.
