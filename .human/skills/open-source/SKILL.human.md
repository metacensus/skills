Publishing cannot be undone, so the check runs before the push. What is internal is a kind of information, not a list: cheap scanners flag anything a lead reaches, and a separate, stronger agent decides which flags are real.

## The mapping

`open-source-mapping.md` holds an organization's intended licenses, its own leads and where examples of them live, and its exceptions, in a private repository. A project may keep its own, linking to the organization's; it adds leads, narrows with exceptions, and wins where both speak. In a public repository it names no examples. A missing section has no rows.

## Two modes

init covers every object a repository has held, with proof, and proposes fixes for the user to decide; review covers one change before it lands, fixes, and says what it changed. Neither gives license advice.

## What a finding is

A real flag, located. The report stays private and a fix names nothing. Secrets are rotated regardless.

## Questions worth asking

Whether private context came along, and what else carries text.
