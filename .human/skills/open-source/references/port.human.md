> A port copies listed sources whole, then strips them.

Fires: porting a sample from a private repo into a public one.

List → Copy → Strip ↺ → Map

⚠️ Listed sources only; a linked file waits until listed.

⚠️ Files, never history; the copy is staged, and only the strip staged over it is committed.

Paths are text: a lead that reaches one renames it.

⚠️ No edit a lead does not reach; rewording waits until the port lands.

Map: source path → destination · what the strip cut, by kind, never the span, in the PR body; ⛔ never the source repo's name.
