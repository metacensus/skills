> A representation stands in for a reality nobody holds; every element costs, so keep few, checked.

## 1 · Reality and perception

### 1.1 Reality and representation

Only as fresh as its last contact with reality.

### 1.2 Elegance

Maximum clarity, fewest elements: one adding no clarity adds only drift. Abstractness is feedback latency, minutes to a decade.

### 1.3 Completeness and attention

Would the gap change an action? Elements thin attention.

## 2 · Information and action

### 2.1 The loop

```
Observation → Current → Future → Action → Past → Observation
```

Drift enters where inference outran contact.

### 2.2 Time as the station

Time is the station, not the tense: a shopping list is future in the shopper's hand, past in a detective's notebook.

### 2.3 The graph

- **Connectedness**: abstract with few dependents is a proposal; concrete with many, load-bearing.
- **The artifact is the node.** A comment is a second node, kept for what the first cannot carry.
- **Edges beat copies.** A duplicate is a missing edge: keep one source, point at it.
- **Derivable is not written.**
- ⚠️ Claims over a set (*the only*) turn false when it grows elsewhere.

## 3 · Drift

### 3.1 Drift

Incorrect: they disagree. Incomplete: reality holds what the graph lacks. Checks refuse incorrectness only; green is never coverage ([§3.4](#34-holes)).

### 3.2 How drift compounds

- **Derivation:** errors inherited downstream.
- **Attention:** drifted regions go unvisited.
- **Residue:** a trace of the replaced pulls the next edit back.
- **Repetition:** nodes that must agree, nothing making them.
- ⚠️ **Misplaced scope**, fastest: architecture in a function comment.

### 3.3 Pricing drift

```
risk = (1 − confidence) × abstractness × connectedness
```

Confidence is the check passed, never fluency: gate · validation · review · bare assertion. ⚠️ Agent output enters at assertion.

### 3.4 Holes

An open question is a named hole at a known scope.

## 4 · Alignment

### 4.1 The orbit

Correct drift faster than it accumulates.

### 4.2 Where information goes

Raise the rung before writing more: artifact · gate · validation · colocation · triggered procedure · scoped note · always-loaded sentence (routing, not knowledge).

Summarize upward, reference sideways, never explain downward.

⚠️ Agents default to addition: carry it in the artifact → link → edit the holder → add one, naming scope and what it retires.

### 4.3 Keeping the loop closed

- Each scope has an instrument and cadence.
- Prune set: low connectedness, assertion confidence.
- Finished: nothing describes what it replaced.
