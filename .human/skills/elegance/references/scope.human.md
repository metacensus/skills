How the skill ranks an element by how long reality takes to show it is wrong.

## Table 1 — Scope (the tier ladder)

Six tiers — principles, field, organization, system, module, file — from decades of latency down to minutes; the bottom three each own a work object: effort, epic, issue.

## Which tier is this?

For the hard bottom three, ask who has to agree: nobody is a file, a module's callers is a module, the other side of a published seam is a system. Many dependents lifts an element's tier; an element explaining a higher tier should move up.

## Along scope

Going up, checks shift from direct tests to reconciliation to none, failures shift from crashes to rework to silent bias, and excess shifts from comments restating code to rules nobody could violate.
