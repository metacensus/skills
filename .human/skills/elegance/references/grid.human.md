Six scopes by three times; each cell has its own file, named for what it holds.

## Reading the grid

Every cell file has the same six sections, including an "Excess" hunt list, because over-writing is the failure at every scope; `check-cells.mts` enforces that skeleton.

## Where the grid collapses

At the file level, plan and fact merge within minutes; at the principle level, one sentence both describes and prescribes. The grid is fully distinct only in the middle tiers, which is where organizations most often have gaps.

## Location key

Each location type is graded by what it enforces on its own: a hard gate (code), partial (APIs, git history), or merely described (everything else). None of them refuses excess, so every location is owed a reader; where a location does not gate, that reader is the only check. The trigger over-fires on purpose, since a spare review is cheaper than a missed defect.
