Tier 0 · scope Principles · time Past

## Example

A rule the organization once lived by · the handbook version that carried it.

## Location

**Archive**, in the location key (grid).

## Clear when

Retired rule kept as it was · one line: why retired + what replaced it · version control is the rung · authored note is an assertion.

## Excess

| Excess | Test or move |
|---|---|
| **The old text copied into the archive note** | Does git hold the old text? It does → link the commit, drop the copy. |
| **A retirement rationale longer than the rule** | One line: why, and what replaced it. |
| **Citations of the retired rule left in the living set** | Grep the living set for the retired rule → every hit outside the archive is rewritten to its replacement. The archive is the only place the old shape survives. |

## Cost

Low · unless still quoted, then residue pulls practice back.

## Moves

1. Retire → one line pointing at the replacement, connected to the commit
2. Archived text → never rewrite; correct only the reason or the replacement note
3. The alteration that matters → in the living set
