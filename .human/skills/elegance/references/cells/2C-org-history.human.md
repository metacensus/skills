> Org history is the archive of superseded visions and annual reports: preserved unedited, findable, never cited as current.

```
            1C field history
                  ↑
2A roadmap ↔ 2B identity ↔ 2C org history
                  ↓
            3C release
```

Tier 2 · scope Organization · time Past

## Example

Earlier versions of the vision · the annual reports that show how it moved.

## Location

**Archive**, in the location key (grid).

## Clear when

unedited since superseded · findable when history is the question · never cited as current

Version control is the rung.

## Excess

| Excess | Test or move |
|---|---|
| **A superseded vision or annual report copied into the archive** | Version control already holds it → extend only where the record system cannot be read when history is the question. |
| **An old vision annotated into a new one** | Superseded text stays as it was; the new vision is [1A](1A-vision.human.md). |

## Cost

Low · residue if an old vision is mistaken for the present one.

## Moves

1. Never rewrite
2. Connect to version control → do not copy from it
