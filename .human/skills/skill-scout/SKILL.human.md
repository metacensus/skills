> Skills are written from evidence: cheap scouts flag, the orchestrator weighs, the person picks.

Fires: what skill to write next, what a skill misses, where agents need correcting.

Sources → batches → `skill-scout-scan` per batch → merge → outline → ⛔ person picks → `sdlc-intake`

| Source | Read |
|---|---|
| sessions | main sessions, last 14 days unless named, by repository, worktrees folded |
| memory | `memory/`, `CLAUDE.md` |
| skills | the session's index, every scout's contract |

A batch, about 2,000 lines, holds one repository's memory and conversations, tool output dropped.

Scouts flag workflows, corrections, friction, and skills silent or wrong; the merge derives recurrence from the refs.

Each candidate: new or edit · target or `none` · one-sentence direction · refs.

⚠️ Evidence stays local; a filed candidate carries its target and direction alone.
