# Ownership Model

Every workflow runs as one owner, and every path, namespace, and policy derives from it. A 403 shows the bug class.

- **P1**: the worker's identity, or a typed owner resolved once.
- **P2**: children stay in context; crossing owners is Nexus.
- **P3**: branch on structure, share functions, never workflow types.
- **P4**: generate policies from the path methods, in one package.
