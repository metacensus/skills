> A rename is per concept, not per string.

Fires: any rename across files.

Anchor → Search → Discover → Map → ⛔ Confirm → Apply

| Step | Does |
|---|---|
| Anchor | one exact string and intent; none → ask |
| Search | whole repo; count before widening |
| Discover | casings, derived terms, file names; group by meaning |
| Map | per concept: spellings, count, target |
| Apply | files, then paths |

⚠️ Names leaving the repo (endpoints, tables, env vars) are flagged for hand change.
