> Work found outside the current scope is filed under the parent that owns it, so that parent's agent picks it up; `sdlc-hygiene` keeps the set honest.

Fires: work a task does not hold; follow-ups; filing an issue.

REST where it serves; writes batched.

|Check|Rule|
|---|---|
|Scope|the current issue's criteria keep their own; a sibling's ruling reaches it|
|Connections|`gh search` open issues, PRs; a match takes a comment|
|Type|Task, Bug or Spike; ⛔ Epic, Initiative|
|Parent|nearest open Epic it serves; none: hygiene's [Adopt](../sdlc-hygiene/SKILL.human.md#adopt)|
|Repository|where its PR lands|
|Form|required fields, its evidence|

**File**: [open-source review](../open-source/references/review.human.md) if public, `gh issue create`, then `sdlc-status --apply`; no label.

**Pickup**: its Epic's crew re-plans over it at Land; else hygiene's missing `ready` raises it.
