> Work found outside the current scope is filed, under its obvious owner if any; `sdlc-hygiene` keeps the set honest.

Fires: work a task does not hold; follow-ups; filing an issue.

Calls chosen for the most per unit of cost, as [hygiene's](../sdlc-hygiene/SKILL.human.md).

|Check|Rule|
|---|---|
|Scope|the current issue's criteria keep their own; a sibling's ruling reaches it|
|Connections|`gh search` open issues, PRs; a match takes a comment|
|Type|Task, Bug or Spike; ⛔ Epic, Initiative|
|Parent|its Epic where the owner is obvious; else none, normal, for hygiene's [Adopt](../sdlc-hygiene/SKILL.human.md#adopt)|
|Filer|the session carrying the parent; others route to it|
|Repository|where its PR lands; third-party only when asked, app unnamed, untyped, unparented|
|Form|parent's type and Initiative read; own type's required fields, its evidence|

**File**: a person's picked set exactly, additions ⛔; [open-source review](../open-source/references/review.human.md) if public; search again, `gh issue create`, then `sdlc-status --apply`; no label.

**Close-out**: every follow-up named filed or dropped before done; the return lists them.

**Defer**: a person's word; moves to an issue with reason and trigger; drop is not planned; removal commented; its enforcement comes off; not asked again, as [human-steps](../human-steps/SKILL.human.md)' questions.

**Pickup**: its Epic's crew re-plans over it at Land; else hygiene's missing `ready` raises it.
