Memory is a proposal nobody else can read; an audit decides, memory by memory, whether it becomes shared, stays personal, or goes.

## The audience names the destination

The broadest audience most of whose readers would be better for a fact: project memory, user-level memory, a repository, the organization's skills, or a general skill. Within it, the skill or contract for the act it governs.

## Verdicts

Retire what is already said, landed, or stale; migrate what serves others; keep what is about the person; split a memory whose facts differ. Open work goes to the tracker.

## Landing

The person decides. Migrations land through review, or as a proposal where you cannot write; the memory retires only once its destination has merged.
