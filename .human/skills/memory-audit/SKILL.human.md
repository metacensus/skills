> Memory is a proposal nobody else can read; the audit gives each fact a verdict.

Fires: reviewing or migrating memories.

Memory → facts → verdict → ⛔ person decides → land → retire

| Audience | Destination |
|---|---|
| you, project | project memory |
| you | user-level memory |
| one repository | that repository |
| the organization | shared skills |
| anyone | a general skill |

Retire if the destination says it or the work landed; migrate if it serves more than this person, keep if it is theirs alone, split if facts differ.

⚠️ Retire a migrated memory only after its destination merges.
