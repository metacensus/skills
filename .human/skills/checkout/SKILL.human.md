> Start each change from current main, in its own worktree and branch.

Fires: picking up an issue; "start", "branch", "check out".

| Step | Does |
|---|---|
| Fetch | cut from `origin/<default>`; resumed → [sync](../checkin/SKILL.human.md#sync) |
| Worktree | one per change; check a harness's base |
| Name | `<your-name>/<topic>`; keep a fixed prefix |
| Stay | its root only; WIP commit, ⚠️ not `git stash` |
