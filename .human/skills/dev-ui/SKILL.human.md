A web UI as its own image, on `dev-ci-github`.

## One path, agreed three times

Base, served directory, and proxy route share one prefix nothing strips, tested in the image.

## A static build, served small

Caddy serves static files: immutable hashed assets, real 404s, a healthcheck.

## The build is the gate

Schema, imports, and types fail it; drafts stay out.

## Interactive only where a page asks

Hydrate where marked, when visible; reach the API through the proxy.

## Sharing with a sibling UI

Same framework majors, no shared package before a second consumer; a copy names its source.
