Publishing cannot be undone, so the check runs before the push. Nearly every leak is a nameable term, so cheap tools and a cheap model find them and the strong model only triages.

## The mapping

Each organization's `disclosure-mapping.md` names its intended licenses and where its internal terms come from. It lives in a private repository; a public one links to it at most, and a session reads it from a clone or through `gh`.

## Two modes

init covers every object a repository has held, with proof; review covers one change before it lands. Neither gives license advice.

## What a finding is

A real hit, located. The report stays private and a fix names nothing. Review fixes before landing; in init the user decides on a rewrite. Secrets are rotated regardless.

## Questions worth asking

Whether private context came along, what else carries text, and what went unread.
